KEY FEATURES:
=============

✓ Semantic Understanding
  - LLM extracts meaning (not just structure)
  - Understands "World without InO" vs "World with InO"
  - Identifies drug names, cost categories, year columns

✓ Hierarchical Detection
  - Parent tables → Children → Grandchildren (up to depth 3)
  - Each level gets its own metadata + summary
  - Preserves relationships in tree structure

✓ Natural Language Summaries
  - 2-3 sentence descriptions for each table
  - Domain-specific terminology (BIM concepts)
  - Explains what the table represents

✓ BIM Ontology Mapping
  - Tags tables with domain concepts
  - cost_analysis, drug_comparison, market_share, etc.
  - Enables knowledge graph queries

✓ Interactive Visualization
  - HTML tree map with drill-down
  - Color-coded by type
  - Hover shows summaries

✓ Q&A System (Future)
  - Natural language questions
  - Data retrieval with citations
  - Follow-up suggestions


COMPARISON WITH V3A:
====================

v3a (Current):
  - Reads xl_table bboxes
  - Detects: title, header, row names, footnotes
  - Uses heuristics (text ratio, formatting)
  - Output: Structural metadata

v4 (New):
  - Reads xl_table bboxes
  - Detects: title, header, row names + CHILDREN + SUMMARIES
  - Uses LLM (semantic understanding)
  - Output: Enriched metadata + hierarchies + knowledge graph
  - Enables: Tree map visualization + Q&A system


COST & PERFORMANCE:
===================

Single Table:
  - 1-2 LLM calls (analysis + ontology)
  - ~$0.02-0.05 per table
  - 2-3 seconds

With Children:
  - +1 LLM call per child
  - ~$0.01-0.02 per child
  - +1-2 seconds per child

Full Workbook (30 tables, 100 children):
  - ~130 LLM calls
  - ~$2.00-3.00 total
  - 60-90 seconds (parallel processing)
