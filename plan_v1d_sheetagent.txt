================================================================
V1D PLAN — VIEWER + HARDENING
================================================================

Context
-------
V1A delivered flat enrichment (scoring, Steps 0-3). V1B added
SheetObjectTree + relationship graphs. V1C added LLM grammar
discovery, Step 4 interpretation, rag_fields. V1D is the final
phase: it adds tree PNG rendering, a thin Streamlit viewer, full
debug trace infrastructure, semantic partition visualization, and
regression tests for all prior phases. V1D is purely additive —
no algorithm changes.

Step 1: Debug Trace Infrastructure
--------------------------------------------

Foundation for all V1D features. No dependencies.

NEW FILE: xl_sheetagent/tools/debug_trace.py

  @dataclass TableTrace:
    table_id: str
    scoring_calls: List[Dict]
    step_entries: List[Dict]
    llm_calls: List[Dict]
    confidence_history: List[Dict]
    decisions: List[Dict]
    final_confidence: float
    final_category: str

  class TraceAccumulator:
    begin_table(table_id)
    record_scoring_call(table_id, function_name, inputs, output)
    record_step(table_id, step_num, event)
    record_llm_call(table_id, prompt_system, prompt_user, response,
                    tokens_in, tokens_out, latency_ms)
    record_decision(table_id, decision_type, details)
    record_confidence(table_id, stage, confidence)
    get_trace(table_id) -> TableTrace
    all_traces() -> Dict[str, TableTrace]

  class ToolCallRecorder:
    record(table_id, system_prompt, user_prompt, response_text,
           tokens_in, tokens_out, latency_ms, model)
    all_records() -> List[Dict]

  def write_debug_outputs(output_path, accumulator, recorder):
    Creates debug/{table_id}_trace.json per table
    Creates debug/tool_call_records.jsonl for all LLM calls
    When debug_level == "minimal": only tool_call_records.jsonl
    When debug_level == "full": both per-table traces and tool call records

Step 2: Tree PNG Rendering
--------------------------------------------

Independent of Step 1. Uses matplotlib Agg backend (same pattern
as xl_image/render/fallback_renderer.py).

NEW FILE: xl_sheetagent/assembly/tree_renderer.py

  Functions:
    render_tree_png(tree, rels, output_path, cfg) -> str
    render_all_trees(trees_by_sheet, rels_by_sheet, output_dir, cfg) -> Dict[str, str]

  Output: sheet_tree_visuals/{safe_sheet_name}_tree.png per sheet

  Layout:
    Hierarchical top-down. Root nodes at top, children below.
    Recursive x/y: x = evenly spaced siblings, y = depth-based.

  Node styling by type:
    section         -> blue rounded rectangle, bold title
    table           -> green rectangle, table_id + title (truncated 30 chars)
    table_partition -> light green, dashed border;
                       non-authoritative = dotted + lower opacity
    context_block   -> gray rectangle
    note            -> yellow rectangle
    shape           -> orange diamond

  Edge styling:
    Parent-child     -> solid gray line
    inherits_header  -> dashed blue arrow
    visualizes       -> dashed purple arrow
    annotates        -> dashed orange arrow
    groups           -> dashed green arrow

  Large sheet handling:
    >50 nodes  -> compact mode (smaller fig, smaller font, no edge labels)
    >100 nodes -> collapse section children into count badge

  Semantic partition overlays:
    For tables with partitions, draw sub-boxes within table node.
    Authoritative = solid green; non-authoritative = dashed lighter green.

  Error handling:
    All rendering in try/except — never crash pipeline.
    On failure: log warning, skip PNG for that sheet.

  - Called from write_outputs after _write_trees
  - Catches all exceptions

Step 4: Streamlit Viewer
--------------------------------------------

Depends on Step 3 (needs enriched bundle).

NEW FILE: apps/streamlit_viewer.py

  Read-only artifact browser.
  Imports ONLY: json, pathlib, pandas, streamlit, PIL.
  Does NOT import any xl_sheetagent modules.

  Run: py -3 -m streamlit run apps/streamlit_viewer.py

  5 Tabs:

  Tab 1 — Overview:
    Load run_manifest.json -> display metrics via st.metric
    Load grammar_discovery_report.json -> confirmed vs observed
    Show text_dominant_sheets count

  Tab 2 — Sheet Browser:
    Sidebar dropdown to select sheet (from streamlit_view_bundle.json)
    Display tree PNG via st.image()
    Table listing: table_id, title, category, confidence, section_path
    Relationship edge count

  Tab 3 — Table Inspector:
    Dropdown to select table by ID
    Full EnrichedTableObject fields from enriched_tables.json
    Semantic partitions with authoritative flags highlighted
    step_log as expandable timeline
    rag_fields, llm_summary
    If debug trace: confidence evolution chart + decision log

  Tab 4 — Grammar Patterns:
    grammar_snapshot.json -> confirmed patterns table
    Observed (unconfirmed) patterns separately
    Guide sheets list

  Tab 5 — Debug Explorer:
    debug_log.jsonl -> filterable dataframe (event_type, table_id)
    debug/tool_call_records.jsonl -> LLM call log
    Search/filter bar

  Session state:
    artifact_dir, selected_sheet, selected_table_id, search_term
