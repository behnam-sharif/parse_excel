================================================================
V1C PLAN — GRAMMAR + IMAGING + STEP 4 LLM INTERPRETATION
================================================================

Context
-------
V1A delivered flat enrichment (5 scoring functions, Steps 0-3, no LLM).
V1B added full deterministic SheetCoordinator, SheetObjectTree, and
relationship graphs (still zero LLM). V1C is the LLM enrichment phase:
it introduces GrammarBuilder for formatting pattern discovery, Step 4
per-partition LLM interpretation (summary, table_category confirmation,
rag_fields), formula-aware payloads, text-dominant sheet handling, and
grammar-aware scoring upgrades.

Key architectural principle: The pipeline must behave identically to
V1B when skip_llm_enrichment=True. Every new code path guards on this
flag.

--------------------------------------------
Step 1: LLM Client Wrapper
--------------------------------------------

Foundation for all LLM calls. No dependencies.

NEW FILE: xl_sheetagent/tools/llm_client.py

  Functions:
    call_llm(system_prompt, user_prompt, cfg) -> str
    call_llm_json(system_prompt, user_prompt, cfg) -> dict
    is_llm_available(cfg) -> bool

  Design:
    - Import OpenAI from openai, client with os.getenv("OPENAI_API_KEY")
    - Load dotenv via core.env_bootstrap.load_project_dotenv()
    - Uses cfg.llm_model and cfg.llm_max_tokens
    - temperature=0 for deterministic results
    - When cfg.skip_llm_enrichment=True: call_llm returns "", call_llm_json returns {}
    - When API key missing and skip=False: raise ValueError with clear message
    - call_llm_json wraps call_llm + JSON parse with fallback on parse failure
    - All exceptions logged, never crash pipeline

  Pattern: same as xl_init/sheet_triage.py (OpenAI, chat completions)

--------------------------------------------
Step 2: GrammarSnapshot Schema + GrammarBuilder
--------------------------------------------

Depends on Step 1 for LLM sheet-name scan.

NEW FILE: xl_sheetagent/schemas/grammar_snapshot.py

  @dataclass GrammarPattern:
    pattern_name: str          # e.g. "bold_merged_section_header"
    pattern_type: str          # section_header | table_title | footnote_marker | repeated_label
    observed_count: int
    observed_sheets: List[str]
    confidence: float          # 0.0-1.0
    status: str                # observed | confirmed
    evidence: Dict[str, Any]   # formatting signature, text pattern

  @dataclass GrammarSnapshot:
    guide_sheets: List[str]
    sample_sheets: List[str]
    patterns: List[GrammarPattern]
    discovery_method: str      # guide_sheet_scan | llm_sheet_name_scan | observed_only
    guide_sheet_confidence: float
    frozen: bool = True

    Methods:
      get_confirmed_patterns(pattern_type) -> List[GrammarPattern]
      has_pattern(pattern_name) -> bool
      grammar_confidence_for_section(formatting_sig: dict) -> float

NEW FILE: xl_sheetagent/modules/grammar_builder.py

  Function:
    build_grammar(upstream, ws_by_sheet, cfg) -> GrammarSnapshot

  Logic:
    1. Guide sheet detection from upstream.approved_sheets
       - Scan names for "Contents", "Index", "TOC", "Summary", "Guide"
    2. Fallback per spec S6.3:
       - candidates conf>0.7 -> use as primary
       - candidates conf<0.7 -> LLM sheet-name scan primary
       - candidates absent -> observed-only mode
       - detected but noisy -> cap declared rules at 0.6
    3. Sample sheet selection: 2-4 sheets with most tables
    4. Pattern scanning:
       - Formatting signatures of rejected_blocks, merged cells, bold rows
       - Group by fill+bold+font_size+merge_span
       - Count occurrences per sheet
    5. Promotion:
       - observed -> confirmed when count >= cfg.grammar_promotion_count (3)
         AND len(sheets) >= cfg.grammar_promotion_sheets (2)
    6. When skip_llm_enrichment=True: skip LLM sheet-name scan, observed-only

MODIFY: xl_sheetagent/schemas/__init__.py
  - Re-export GrammarPattern, GrammarSnapshot

Step 3: V1C Payload Builder Modes
--------------------------------------------

No dependencies. Needed by Steps 5-6.

MODIFY: xl_sheetagent/tools/payload_builder.py

  Add 4 new modes to build_payload():

  1. "header_plus_sample_body"
     - Header row(s) + first N body rows as text
     - For LLM table interpretation context

  2. "local_title_context"
     - Title row + 2 rows above + first 2 body rows
     - For LLM title/section inference

  3. "summary_context"
     - Full table context
     - For formula_ratio > 0.5: include first 2 rows of A1-style formulas
       (do NOT strip). Uses ws_formula (data_only=False worksheet)
     - Otherwise: text-only

  4. "partition_summary_context"
     - Same as summary_context but scoped to a partition's sub_bbox

  Signature change:
    build_payload(..., ws_formula: Optional = None)
    (existing _extract_rows text_only flag handles formula pass-through)

Step 4: Text-Dominant Sheet Detection
--------------------------------------------

Depends on Step 1 for LLM summaries.

NEW FILE: xl_sheetagent/modules/text_dominant_handler.py

  @dataclass TextDominantResult:
    sheet_name: str
    is_text_dominant: bool
    text_ratio: float
    chunks: List[Dict[str, Any]]       # classified text chunks
    sheet_summary: Optional[str]       # LLM-generated or deterministic
    classification: str                # intro | assumptions | references | repeated

  Function:
    detect_text_dominant_sheets(upstream, ws_by_sheet, cfg) -> Dict[str, TextDominantResult]

  Logic:
    - For each sheet: compute text_cell_ratio across all tables
      (reuse formula_ratio logic from table_enricher.py)
    - If ratio > cfg.text_dominant_sheet_threshold (0.70): mark text_dominant
    - Text-dominant sheets: read in chunks, classify as intro/assumptions/references/repeated
    - If LLM available: generate sheet-level text summary
    - Else: concatenate titles + first lines

MODIFY: xl_sheetagent/schemas/enriched_table.py
  - Add: sheet_level_text_dominant: bool = False
  - Add: sheet_text_summary: Optional[str] = None

--------------------------------------------
Step 5: Step 4 LLM Interpretation (per partition)
--------------------------------------------

Depends on Steps 1, 2, 3.

NEW FILE: xl_sheetagent/steps/step4_interpretation.py

  @dataclass InterpretationResult:
    summary: str
    table_category: str
    table_category_confidence: float
    rag_fields: Dict[str, Any]  # embedding_description, key_entities, table_category, section_path
    semantic_hint: str

  Functions:
    interpret_partition(table, partition_idx, ws_data_only, ws_formula, grammar, cfg)
      -> InterpretationResult

    run_step4_interpretation(enriched_tables, ws_by_sheet, ws_formula_by_sheet, grammar, cfg)
      -> List[EnrichedTableObject]

  LLM system prompt:
    "You are a financial spreadsheet analyst. Given a table excerpt, provide:
     1. A concise summary (1-2 sentences)
     2. Classify as one of: input, assumption, calc, output, reference, note, summary
     3. Key entities (drug names, comparators, parameters)
     4. An embedding-optimized description (1 sentence for retrieval)
     Respond with JSON: {summary, table_category, key_entities, embedding_description}"

  User prompt: built via build_payload("summary_context", ...) or
    build_payload("partition_summary_context", ...)

  Rules:
    - Runs PER PARTITION; tables without partitions treated as one partition
    - table_category from LLM overwrites V1A inference when LLM conf > existing
    - rag_fields = {embedding_description, key_entities, table_category, section_path}
    - When skip_llm_enrichment=True: return deterministic defaults

MODIFY: xl_sheetagent/schemas/enriched_table.py
  - Add: rag_fields: Dict[str, Any] = field(default_factory=dict)
  - Add: semantic_hint: str = ""
  - Add: llm_summary: Optional[str] = None
  - Add: llm_table_category: Optional[str] = None
  - Add: llm_table_category_confidence: float = 0.0

Step 8: Main Entry Wiring + Exporter + Manifest
--------------------------------------------

MODIFY: xl_sheetagent/__init__.py

  New orchestration flow:

    upstream = load_upstream(run_id)

    # Open workbooks (data_only=True + data_only=False for formulas)
    ws_by_sheet = {...}
    ws_formula_by_sheet = {...}

    # Phase 0: Grammar discovery (NEW)
    grammar = build_grammar(upstream, ws_by_sheet, config)

    # Phase 0b: Text-dominant detection (NEW)
    text_dominant = detect_text_dominant_sheets(upstream, ws_by_sheet, config)

    # Phase 1: Enrichment (Steps 0-3 + V1C confirmations)
    enriched_tables, signals, debug = enrich_all_tables(upstream, config, grammar=grammar)

    # Phase 2: Coordinator (grammar-aware scoring)
    enriched_tables, signals, trees, rels, debug = coordinate_sheet(
        ..., grammar=grammar
    )

    # Phase 3: Step 4 LLM interpretation (NEW — per partition)
    enriched_tables = run_step4_interpretation(
        enriched_tables, ws_by_sheet, ws_formula_by_sheet, grammar, config
    )

    # Phase 4: Export (updated)
    write_outputs(..., grammar=grammar, text_dominant=text_dominant)
