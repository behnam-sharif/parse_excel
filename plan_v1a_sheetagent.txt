xl_sheetagent V1A Implementation Plan
======================================

0. CONTEXT
======================================

xl_sheetagent is Stage 4 in the xlgen pipeline (after xl_table, before
future xl_ontology/xl_ask). Takes structural tables from xl_table, adds
titles, headers, notes, table categorization, and produces enriched table
objects for downstream consumption.

V1A = scoring + flat enrichment only. No grammar, no imaging, no section
skeleton, no tree rendering, no full SheetCoordinator, no LLM Step 4.

Establishes: package scaffold, 5 deterministic scoring functions, upstream
compatibility, content_bbox/context_block pre-filtering, boundary validation
(Steps 1-3), deterministic table_category inference.

V1B-V1D are subsequent phases -- V1A lays foundations without over-building.

Step 4: scoring.py -- THE CORE
--------------------------------------------

NEW FILE: xl_sheetagent/scoring.py

All 5 functions deterministic, no LLM, independently testable. >=10 tests each.

  4.1 title_attachment_score(
        spatial_distance, text_match, grammar_match, shape_match,
        is_merged_full_width, is_bold, has_formula
      ) -> float [0,1]
    Logic:
      base = exponential_decay(spatial_distance): 0->1.0, 1->0.85, 2->0.65, 3->0.40
      if is_merged_full_width: base *= 1.15
      if is_bold: base *= 1.05
      if has_formula: base *= 0.1
      if grammar_match: base += 0.15
      if shape_match: base += 0.10
      if text_match: base += 0.10
      return clamp(base, 0, 1)

  4.2 section_ownership_score(
        band_proximity, formatting_match, grammar_confidence,
        table_count_under, is_full_width, has_merge_span
      ) -> float [0,1]
    Logic:
      if table_count_under == 0: return 0.05
      base = exponential_decay(band_proximity)
      if is_full_width: base *= 1.20
      if has_merge_span: base *= 1.10
      if formatting_match: base += 0.15
      base += grammar_confidence * 0.20
      return clamp(base, 0, 1)

  4.3 header_inheritance_score(
        column_range_overlap, row_proximity, formatting_similarity,
        same_section, source_has_headers
      ) -> float [0,1]
    Logic:
      if not source_has_headers: return 0.0
      if column_range_overlap < 0.50: return 0.05
      base = column_range_overlap
      prox_decay = exponential_decay(row_proximity): 0->1.0, 3->0.70, >10->0.10
      base *= prox_decay
      if formatting_similarity: base += 0.10
      if same_section: base += 0.10
      return clamp(base, 0, 1)

  4.4 note_scope_score(
        spatial_distance, text_keywords, table_count_nearby,
        is_after_last_table
      ) -> (scope: str, confidence: float)
    Logic:
      if distance <= 1 and count == 1:        return ('single_table', 0.90)
      if after_last and 'all' in keywords:    return ('sheet', 0.85)
      if after_last and no keywords:          return ('sheet', 0.60)
      if count > 1 and distance <= 3:         return ('section', 0.70)
      else:                                   return ('ambiguous', 0.40)

  4.5 column_split_score(
        col_separator_score, formatting_discontinuity,
        header_group_break, tile_evidence, bbox_width
      ) -> float [0,1]
    Logic:
      base = col_separator_score
      base += formatting_discontinuity * 0.15
      if header_group_break: base *= 1.25
      base += tile_evidence * 0.20   # V1C only, 0 in V1A
      if bbox_width < 6: base *= 0.5
      return clamp(base, 0, 1)

Step 7: Step 0 (content_bbox + context_block)
--------------------------------------------

NEW FILES:
  xl_sheetagent/steps/__init__.py
  xl_sheetagent/steps/step0_prefilter.py

Step 0A -- content_bbox:
  compute_content_bbox(table_object, accessor) -> (content_bbox, empty_zones[])
    Scan within table bbox for tightest non-empty sub-region.
    Classify empty zones: leading_rows, trailing_rows, leading_cols, trailing_cols, internal.
    Leading/trailing -> trimmable=True. Internal -> trimmable=False (split evidence for Step 2).
    Append to step_log: {"step":0, "action":"content_bbox_computed", ...}

Step 0B -- context_block:
  check_context_block(table_object, all_tables, cfg) -> bool
    ALL must be true:
      formula_ratio < cfg.context_block_formula_ceil (0.05)
      row_count <= cfg.context_block_max_rows (5)
      adjacent to (within cfg.context_block_adjacency_max rows) another TableObject
    If true: is_context_block=True, emit orphan_rows signal (content_type="context_block").
    Do NOT run Steps 1-3 for context blocks.
    Append to step_log: {"step":0, "action":"context_block_routed", ...}

  formula_ratio note: xl_table opens data_only=True so formula_ratio may be 0.0.
  V1A approach: recompute by opening cleaned_workbook.xlsx with data_only=False
  via a secondary accessor for the table bbox. Cache per-sheet. On failure, fall
  through to 'unknown' category.

Step 1 -- Boundary validation (step1_boundary.py):
  validate_boundaries(table, context_rows, shapes, cfg)
    -> (title, footnotes, signals[])
    Scan rows above table (up to cfg.title_shape_proximity_max).
    Score each candidate with title_attachment_score().
    >= cfg.tier_a_sufficient (0.80): accept title (Tier A).
    < tier_a_sufficient: emit orphan_rows signal (Tier B).
    Scan rows below for footnotes via note_scope_score().
    Check shapes for text boxes near table.
    Log every scoring call to debug_log.

Step 2 -- Split detection (step2_splits.py):
  detect_splits(table, content_bbox, empty_zones, cfg)
    -> semantic_partitions[]
    Check internal empty zones from Step 0 as column-split evidence.
    Score with column_split_score().
    Grep provenance for split indicators.
    >= cfg.split_reconsideration_min: create SemanticPartition (advisory only).
    Log every scoring call.

Step 3 -- Header resolution (step3_headers.py):
  resolve_headers(table, upstream_data, shapes, rejected_blocks, cfg)
    -> (column_headers, row_headers, signals[])
    Level 1: upstream header_row_indices + header_confidence.
      If confidence >= tier_a_sufficient: accept (Tier A).
    Level 2: shapes for header text boxes.
      Score with title_attachment_score (shape_match=True).
    Level 3: rejected_blocks.jsonl spatial overlap/proximity.
      Filter by sheet_name, look for header bands.
    Level 4 (V1C only): LLM fallback -- SKIP in V1A.
    If unresolved: emit header_unresolved signal.

table_enricher.py -- orchestrates Steps 0-3:
  enrich_table(table_object, upstream_data, accessor, all_tables, cfg)
    -> (EnrichedTableObject, signals[])
    Step 0: content_bbox + context_block
    If context_block: return early with minimal enrichment
    Step 1: boundary validation
    Step 2: split detection
    Step 3: header resolution
    Assemble EnrichedTableObject
    Return enriched table + signals

Step 9: table_category partial inference
--------------------------------------------

Integrated into table_enricher.py (after Steps 1-3, before return).

  infer_table_category(table, content_bbox, is_context_block)
    -> (category, confidence, reasoning)

  V1A rules (deterministic, no LLM):
    context_block == True            -> ('note', 0.70, 'context_block')
    formula_ratio > 0.70             -> ('calc', 0.60, 'high formula ratio')
    formula_ratio < 0.05 and rows<=5 -> ('note', 0.55, 'small text block')
    formula_ratio < 0.10 and all text-> ('reference', 0.50, 'text-dominant')
    otherwise                        -> ('unknown', 0.0, 'insufficient signal')

  formula_ratio: recomputed via data_only=False accessor (see Step 7 note).
  On failure: fall through to 'unknown'.

3. KEY DESIGN DECISIONS
======================================

1. formula_ratio recomputation:
   Open cleaned_workbook.xlsx with data_only=False via secondary accessor.
   Compute per-table bbox. Cache per-sheet. Fall through to 'unknown' on failure.

2. debug_log.jsonl:
   Every scoring function call logged (function name, inputs, output, timestamp).
   Sheet/run-scope events go here. Table-scope events go to step_log[] on
   EnrichedTableObject.

3. No LLM in V1A:
   payload_builder exists for text extraction but no LLM calls made.
   skip_llm_enrichment defaults to True. SheetCoordinator is pass-through.

4. Workbook access:
   Use openpyxl directly in xl_sheetagent (lightweight accessor).
   Do NOT import from xl_table (avoid cross-stage coupling).

5. Relative imports within package:
   from .scoring import title_attachment_score
   Cross-package shared types via: from core.visual_types import ...

6. No xl_kg substring:
   Enforced by existing TestNoLegacyKgSubstring (auto-includes xl_sheetagent).

======================================
7. INTENTIONAL DEVIATIONS FROM SPEC
======================================

7.1 rejected_blocks vs SheetCoordinator (spec S6.2)

  Spec says SheetCoordinator loads rejected_blocks.jsonl FIRST before other
  signal resolution. V1A deviation: rejected_blocks used only in TableEnricher
  Step 3 (header resolution Level 3) -- the coordinator is a no-op pass-through.

  V1B will add the coordinator-first index over rejected_blocks keyed by
  sheet_name + spatial order (spec S6.2 load order). If duplicate logic exists
  between Step 3 and the coordinator at that point, consolidate into coordinator
  and have Step 3 call the coordinator's index. This is an intentional V1A
  simplification -- documented here so V1B doesn't fight the spec.

7.2 Tests location

  V1A places unit tests under xl_sheetagent/tests/ (co-located with the package).
  The repo's existing integration/smoke tests live in tests/ (root) with conftest.py.

  Convention for V1A:
    - xl_sheetagent/tests/   -> package-level unit tests (scoring, upstream_compat,
      prefilter, boundary, splits, headers). Run: py -3 -m pytest xl_sheetagent/tests/ -v
    - tests/test_smoke.py    -> import/config smoke tests (extended to include xl_sheetagent).
      Run: py -3 -m pytest tests/ -v
    - CI must run BOTH: py -3 -m pytest tests/ xl_sheetagent/tests/ -v

  xl_sheetagent/tests/conftest.py will add the repo root to sys.path (same as
  the root conftest.py) so imports work consistently from either test location.

7.3 run_sheetagent API and core/paths

  The public API is: run_sheetagent(run_id, output_path=None, config=None)

  Production path: output_path defaults to None. When None, the function resolves
  output via get_sheetagent_output_path(run_id) from core/paths.py, enforcing the
  run-root rule.

  output_path is an explicit override for tests and one-off usage ONLY. When
  provided, it bypasses core/paths resolution. Document this in the function
  docstring: "output_path overrides the run-root policy; use only for tests."

  Same pattern as xl_table/__init__.py where parse_output_path is passed
  explicitly but production scripts always derive it from run_id.

7.4 cell_features preservation in upstream_compat

  V1B SheetCoordinator needs cell_features from candidate_rows.jsonl (fill_color
  groups, font size, border data) for section skeleton detection without xl_image.

  V1A requirement: upstream_compat normalizes candidate_rows lines and MUST retain
  cell_features as an OPTIONAL pass-through field (empty dict if absent). V1A does
  not read or interpret cell_features, but the field is preserved on the normalized
  UpstreamData.candidate_rows dicts so V1B can consume it without a compat break.

  Add to UpstreamData or the per-candidate normalized dict:
    cell_features: dict    # OPTIONAL -> empty dict if absent; V1A pass-through
